## Logo

### Concept
Open book (flat, symmetric) with three minimal learning elements floating above
the spine in a gentle upward arc.

### Floating elements
- `A` — left, lowest
- `1` — center, mid-height
- `★` — right, highest

### Sizing rules
- Floating elements: ~25–30% of book icon height
- No drop shadows, no gradients — flat fill only
- Minimum clear space: equal to the height of the "A" element on all sides

### Versions to export

| Version | Contents | Size | Format | Use |
|---|---|---|---|---|
| Full logo (stacked) | Icon + store name + tagline | 1000×500px | PNG (transparent) | Lemon Squeezy store header |
| Full logo (horizontal) | Icon + store name | 800×200px | PNG (transparent) | Email headers, social bios |
| Icon only | Book + floating elements | 512×512px | PNG (transparent) | Gumroad avatar, social profile pic |
| Favicon | Book silhouette only (no floats, no text) | 512×512px | PNG (transparent) | Upload to favicon.io for auto-resize |

## Product Cover Image Spec

All listing thumbnails should follow this template for visual consistency.

### Canvas size
1920 × 1080px (16:9) — Lemon Squeezy preferred

### Layout zones
```
┌─────────────────────────────────────────────────┐
│  [Top-left: small logo mark — 80px tall]        │
│                                                 │
│         [Center: product screenshot             │
│          or worksheet preview — 60% of canvas]  │
│                                                 │
│  [Bottom bar: product title + badge]            │
│  Background color: #F5C518 or #F6F6F0           │
└─────────────────────────────────────────────────┘
```

### Badge styles
- Shape: rounded rectangle, 8px radius
- Text: Nunito ExtraBold, white `#FFFFFF`, 28px
- Background: Coral Orange `#FF7D52`
- Examples: `20+ Pages` · `Instant Download` · `Printable PDF` · `Free Sample`

## Do's and Don'ts

| ✅ Do | ❌ Don't |
|---|---|
| Use flat, clean shapes only | Add drop shadows or gradients to the logo |
| Stick to the 6-color palette | Introduce new colors on product covers |
| Use Poppins for all titles | Mix more than 2 fonts in any single design |
| Keep floating elements (A, 1, ★) small and subtle | Make them compete with the book icon in size |
| Export favicon as book silhouette only | Use the full logo (with text) as a favicon |
| Use `#F6F6F0` off-white as page background | Use pure white `#FFFFFF` as the canvas background |
| Maintain light backgrounds on worksheet previews | Use dark backgrounds on product screenshots |
